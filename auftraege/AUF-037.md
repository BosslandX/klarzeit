# AUF-037 — Hinweise nach dem Arbeitszeitgesetz (nur in der App)

## Auftrag

Neues reines Modul `src/domain/arbzg.ts` mit `arbzgHints(entries, day)`: Hinweise für einen Kalendertag,
über alle Beschäftigungen zusammen — mehr als 10 Stunden, zu kurze Pausen, mehr als 6 Stunden am Stück,
zu kurze Ruhezeit. „Erfassung" zeigt die Hinweise für heute, „Einträge" unter jedem Tag. Nur Hinweise,
keine Sperre, nicht im PDF.

## Warum das gebraucht wird

Punkt 7 des mit dem Nutzer abgestimmten Plans. **Am 2026-11-17 wörtlich an gesetze-im-internet.de
geprüft:**

- § 2 Abs. 1 Satz 1 ArbZG: „Arbeitszeiten bei mehreren Arbeitgebern sind zusammenzurechnen".
- § 3 ArbZG: „Sie kann auf bis zu zehn Stunden nur verlängert werden".
- § 4 Satz 1 ArbZG: Ruhepausen „von mindestens 30 Minuten bei einer Arbeitszeit von mehr als sechs bis zu
  neun Stunden und 45 Minuten bei einer Arbeitszeit von mehr als neun Stunden insgesamt"; Satz 2: „in
  Zeitabschnitte von jeweils mindestens 15 Minuten"; Satz 3: „Länger als sechs Stunden hintereinander
  dürfen Arbeitnehmer nicht ohne Ruhepause beschäftigt werden."
- § 5 Abs. 1 ArbZG: „eine ununterbrochene Ruhezeit von mindestens elf Stunden".

**Festgelegt (vom Auftraggeber, nicht ändern):**

- Ein Eintrag zählt zu dem Tag, an dem er beginnt (wie überall in der App).
- Pausen: Mit Uhrzeit zählen nur Abschnitte ab 15 Minuten, ohne Uhrzeit die eingetragenen Minuten; dazu
  Lücken ab 15 Minuten zwischen Einträgen desselben Tages.
- „Mehr als 6 Stunden am Stück" nur, wo die Lage der Pausen bekannt ist — ein Eintrag mit Pause ohne
  Uhrzeit bleibt dafür außen vor, statt einen falschen Hinweis zu erzeugen.
- Ruhezeit: vom Ende der letzten Arbeit an einem früheren Tag bis zum ersten Beginn des Tages.
- Nicht abgebildet: die Voraussetzungen der Verlängerung nach § 3 und die Ausnahmen des Gesetzes — die App
  weist nur auf mehr als 10 Stunden hin.

## Was zu tun ist

### 0 — Drei getrennte Einspiel-Läufe, in dieser Reihenfolge, jeder genau einmal

**Erst wenn ein Schritt gemessen ist, wird das Skript des nächsten geschrieben** — auch keine Dateien
für einen späteren Schritt vorher anlegen. Die Zeitstempel werden nachgesehen.

1. `auftraege/_probe/AUF-037_teil1.py` spielt das **Gerüst** (Schritt 1) ein → `npx tsc --noEmit` und
   `npx vitest run`, Ausgabe nach `auftraege/_ergebnisse/AUF-037_geruestlauf.txt`.
2. `auftraege/_probe/AUF-037_teil2.py` spielt die **Tests** (Schritt 2) ein → `npx tsc --noEmit` und
   `npx vitest run`, die **vollständige, wörtliche** Ausgabe von vitest (stdout und stderr, als UTF-8)
   **sofort** nach `auftraege/_ergebnisse/AUF-037_ausgangslauf.txt` — **kein Auszug**. Diese Datei danach
   **nie wieder schreiben**.
3. Erst dann `auftraege/_probe/AUF-037_teil3.py` mit der **Umsetzung** (Schritt 3).

**Kein Schritt läuft zweimal.** Jedes Teilskript prüft vor dem Schreiben je Stück: das Suchstück kommt
**genau einmal** vor, und der Ersatz steht **noch nicht** in der Datei; sonst Abbruch ohne Schreiben. Es
legt vorher Kopien der betroffenen Dateien unter `auftraege/_probe/AUF-037_vorher/teilN/` ab. Muss ein
Schritt doch wiederholt werden: erst von dort zurückholen, dann neu — und mit Uhrzeit in
`nicht_erreicht`. **Eigene Zwischenabnahmen nur mit einer Lieferung, deren Befehle keine Einspielskripte
enthalten.** (AUF-036 lief so sauber durch — bitte genauso.)

**Jedes Suchstück kommt schon in der Ausgangsdatei seines Schritts genau einmal vor** (vom Auftraggeber
so geprüft).

**Zeilenenden je Datei feststellen, nicht annehmen:** als **Bytes** lesen; enthält die Datei `\r\n`,
Suchstück und Ersatz **genau einmal** von `\n` nach `\r\n` umwandeln (den LF-Text aus dem Auftrag, nie
einen Text, der schon `\r` enthält), sonst unverändert anwenden. Vor dem Schreiben prüfen, dass keine
Datei `\r\r` enthält. Neue Dateien mit LF, jede endet mit **genau einem** Zeilenumbruch (in AUF-036 stand
am Ende einer Testdatei eine Leerzeile zu viel). Codierung UTF-8; die Stücke enthalten `–` (U+2013) und
`§` (U+00A7), die genau so bleiben.

Unter Windows sind `npx` und `npm` `.cmd`-Dateien: im Hilfsskript `npx.cmd`/`npm.cmd` aufrufen oder
`shell=True` setzen.

**Negativkontrollen nur an einer Kopie** des **endgültigen** Stands, nie am Arbeitsstand: `src/`,
`package.json`, `vite.config.ts` und `tsconfig.json` nach `auftraege/_probe/AUF-037_nk/` kopieren und dort
mutieren und messen (`npx vitest run` mit diesem Ordner als Arbeitsverzeichnis). Die NK-Ergebnisdatei
schreibt das NK-Skript **vor** der Lieferung; danach weder die Lieferung noch die Ergebnisdatei neu
schreiben.

```ts
export function arbzgHints(entries: readonly TimeEntry[], day: number): string[] {
  const tagStart = startOfDay(day).getTime();
  const tag = entries
    .filter((e) => startOfDay(e.start).getTime() === tagStart)
    .sort((a, b) => a.start - b.start);
  if (tag.length === 0) return [];
  const arbeitMs = tag.reduce((s, e) => s + netMs(e), 0);
  const luecken = tag.slice(1).reduce((s, e, i) => {
    const luecke = e.start - tag[i].end;
    return luecke >= RUHEPAUSE_MIN_MS ? s + luecke : s;
  }, 0);
  const pauseMin = Math.round((tag.reduce((s, e) => s + pausenMs(e), 0) + luecken) / MINUTE);
  const noetig = arbeitMs > 9 * HOUR ? 45 : arbeitMs > 6 * HOUR ? 30 : 0;
  const ruhe = ruhezeitMs(entries, tag[0].start);
  return [
    ...(arbeitMs > HOECHST_MS
      ? [`Mehr als 10 Stunden gearbeitet (${formatDuration(arbeitMs)}) – § 3 ArbZG`]
      : []),
    ...(pauseMin < noetig
      ? [`Pausen ${pauseMin} statt mindestens ${noetig} Minuten – § 4 ArbZG`]
      : []),
    ...(laengsterBlockMs(tag) > AM_STUECK_MS
      ? ['Mehr als 6 Stunden ohne Ruhepause – § 4 ArbZG']
      : []),
    ...(ruhe !== undefined && ruhe < RUHEZEIT_MS
      ? [`Ruhezeit nur ${formatDuration(ruhe)} statt mindestens 11 Stunden – § 5 ArbZG`]
      : []),
  ];
}

/** Pause eines Eintrags: mit Uhrzeit nur Abschnitte ab 15 Minuten, sonst die eingetragenen Minuten. */
function pausenMs(e: TimeEntry): number {
  if (!e.breaks || e.breaks.length === 0) return e.breakMinutes * MINUTE;
  const teile = workSegments(e);
  return teile.slice(1).reduce((s, t, i) => {
    const luecke = t.start - teile[i].end;
    return luecke >= RUHEPAUSE_MIN_MS ? s + luecke : s;
  }, 0);
}

/**
 * Laengste Arbeit am Stueck: Abschnitte mit weniger als 15 Minuten dazwischen gelten als einer.
 * Eintraege mit Pause ohne Uhrzeit bleiben aussen vor -- wo die Pause lag, ist unbekannt.
 */
function laengsterBlockMs(tag: readonly TimeEntry[]): number {
  const teile = tag
    .filter((e) => !(e.breakMinutes > 0 && (!e.breaks || e.breaks.length === 0)))
    .flatMap((e) => workSegments(e))
    .sort((a, b) => a.start - b.start);
  const bloecke = teile.reduce<{ start: number; end: number }[]>((out, t) => {
    const letzter = out[out.length - 1];
    if (letzter !== undefined && t.start - letzter.end < RUHEPAUSE_MIN_MS) {
      return [...out.slice(0, -1), { start: letzter.start, end: Math.max(letzter.end, t.end) }];
    }
    return [...out, t];
  }, []);
  return bloecke.reduce((m, b) => Math.max(m, b.end - b.start), 0);
}

/** Ruhezeit vor `beginn` seit dem Ende der Arbeit an einem frueheren Tag; ohne solche undefined. */
function ruhezeitMs(entries: readonly TimeEntry[], beginn: number): number | undefined {
  const tagStart = startOfDay(beginn).getTime();
  const ende = entries
    .filter((e) => e.start < tagStart && e.end <= beginn)
    .reduce<number | undefined>((m, e) => (m === undefined || e.end > m ? e.end : m), undefined);
  return ende === undefined ? undefined : beginn - ende;
}
```
