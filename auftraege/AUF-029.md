# AUF-029 — Feiertage im Arbeitszeitkonto und beim Urlaub

## Auftrag

Eine Beschäftigung trägt ihre Feiertagseinstellung (`publicHolidays`), und Konto, Urlaubszeitraum und
Urlaubszählung rechnen mit diesen Feiertagen — ohne Oberfläche.

## Warum das gebraucht wird

Feiertage erzeugen heute Minusstunden. AUF-028 hat die Berechnung geliefert (`src/domain/holidays.ts`);
dieser Auftrag schließt sie an. **Entscheidung des Nutzers (2026-11-17):** Feiertage je Bundesland,
regionale zuschaltbar, eigene Tage ergänzen oder streichen, **ohne Einstellung bleibt alles wie heute**.

Die Regeln, vom Auftraggeber an den amtlichen Fassungen geprüft:

- **Gutschrift:** „Für Arbeitszeit, die infolge eines gesetzlichen Feiertages ausfällt, hat der
  Arbeitgeber dem Arbeitnehmer das Arbeitsentgelt zu zahlen, das er ohne den Arbeitsausfall erhalten
  hätte." (§ 2 Abs. 1 EntgFG). Im Konto heißt das: ein Feiertag an einem **eigenen Arbeitstag** füllt wie
  ein Urlaubstag bis zum Tagessoll auf; was an dem Tag gearbeitet wurde, zählt als Ist, gutgeschrieben wird
  der Rest. Urlaub und Feiertage teilen sich den Monatsdeckel: zusammen höchstens das Soll.
- **Urlaub am Feiertag:** „Als Werktage gelten alle Kalendertage, die nicht Sonn- oder gesetzliche
  Feiertage sind." (§ 3 Abs. 2 BUrlG). Ein Urlaubstag auf einem Feiertag zählt deshalb weder als genommen
  noch in der Urlaubsgutschrift, und ein eingetragener Zeitraum überspringt Feiertage.

Der nächste Auftrag bringt die Oberfläche (Auswahl im Formular, Zeile in Auswertung und PDF, Hinweis am
Urlaubstag).

export function cleanPublicHolidays(raw: unknown): PublicHolidays | undefined {
  if (typeof raw !== 'object' || raw === null) return undefined;
  const x = raw as Record<string, unknown>;
  const land = BUNDESLAENDER.find((l) => l.code === x.land)?.code;
  if (land === undefined) return undefined;
  const gewaehlt = Array.isArray(x.regional) ? (x.regional as unknown[]) : [];
  const regional = REGIONALE_FEIERTAGE[land]
    .map((r) => r.key)
    .filter((k) => gewaehlt.includes(k));
  return { land, regional, extra: tagesliste(x.extra), skip: tagesliste(x.skip) };
}

/** Tage aus einer gespeicherten Liste: endliche Zahlen auf lokale Mitternacht, aufsteigend. */
function tagesliste(raw: unknown): number[] {
  if (!Array.isArray(raw)) return [];
  const tage = raw
    .filter((v): v is number => typeof v === 'number' && Number.isFinite(v))
    .map((v) => startOfDay(v).getTime());
  return [...new Set(tage)].sort((a, b) => a - b);
}

/**
 * Feiertage eines Monats an eigenen Arbeitstagen und die Gutschrift dafuer (AUF-029). Wie
 * beim Urlaub fuellt sie nur bis zum Tagessoll auf: Arbeit am Feiertag zaehlt als Ist,
 * gutgeschrieben wird der Rest. Grundlage: das Entgelt fuer Arbeitszeit, die infolge eines
 * gesetzlichen Feiertages ausfaellt (§ 2 Abs. 1 EntgFG).
 */
function holidaysOfMonth(
  emp: Employment,
  entries: readonly TimeEntry[],
  monthRef: number,
): { days: number; creditMs: number } {
  const mStart = startOfMonth(monthRef).getTime();
  const mEnd = endOfMonth(monthRef).getTime();
  const empStart = startOfDay(emp.startDate).getTime();
  const empEnd = emp.endDate != null ? endOfDay(emp.endDate).getTime() : Infinity;
  const arbeitstage = workWeekdaysOf(emp);
  const jahr = getYear(monthRef);
  const tage = [...publicHolidayMap(emp.publicHolidays, jahr, jahr).keys()].filter(
    (d) =>
      d >= mStart &&
      d <= mEnd &&
      d >= empStart &&
      d <= empEnd &&
      arbeitstage.includes(getDay(d)),
  );
  const perDay = dailyTargetMs(emp);
  const creditMs = tage.reduce((sum, day) => {
    const dayEnd = endOfDay(day).getTime();
    const istOfDay = entries.reduce(
      (s, e) =>
        e.start >= day && e.start <= dayEnd && e.start >= empStart && e.start <= empEnd
          ? s + netMs(e)
          : s,
      0,
    );
    return sum + Math.max(0, perDay - istOfDay);
  }, 0);
  return {
    days: tage.length,
    creditMs: Math.round(creditMs / MINUTE) * MINUTE,
  };
}
