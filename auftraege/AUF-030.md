# AUF-030 — Feiertage in Formular, Urlaubsliste, Auswertung und PDF

## Auftrag

Die Feiertagseinstellung aus AUF-029 wird bedienbar und sichtbar: Auswahl im Beschäftigungsformular,
Hinweis am Urlaubstag, Zeile in Auswertung und PDF-Kontoblock.

## Warum das gebraucht wird

AUF-028/029 rechnen Feiertage, aber niemand kann sie einschalten. **Entscheidung des Nutzers
(2026-11-17):** Bundesland des Arbeitsorts wählen, regionale Tage zuschalten, eigene Tage ergänzen oder
streichen; ohne Land bleibt alles wie heute. Die Oberfläche zeigt deshalb eine Vorschau des laufenden
Jahres, in der jeder Landesfeiertag gestrichen und wieder zurückgeholt werden kann, und eigene Tage.

## Was zu tun ist

### 0 — Drei getrennte Einspiel-Läufe, in dieser Reihenfolge

**Erst wenn ein Schritt gemessen ist, wird das Skript des nächsten geschrieben** — in AUF-025, AUF-027,
AUF-028 und AUF-029 standen alle drei Skripte in den ersten Minuten im Ordner. Die Zeitstempel werden
wieder nachgesehen, Abweichungen gehören in `nicht_erreicht`.

1. `auftraege/_probe/AUF-030_teil1.py` spielt das **Gerüst** (Schritt 1) ein → `npx tsc --noEmit` und
   `npx vitest run`, Ausgabe nach `auftraege/_ergebnisse/AUF-030_geruestlauf.txt`.
2. `auftraege/_probe/AUF-030_teil2.py` spielt die **Tests** (Schritt 2) ein → `npx tsc --noEmit` und
   `npx vitest run`, die **vollständige, wörtliche** Ausgabe von vitest (stdout und stderr) **sofort** nach
   `auftraege/_ergebnisse/AUF-030_ausgangslauf.txt` — **kein Auszug**. Diese Datei danach **nie wieder
   schreiben**.
3. Erst dann `auftraege/_probe/AUF-030_teil3.py` mit der **Umsetzung** (Schritt 3).

**Jedes Suchstück kommt in seiner Datei genau einmal vor**; das Skript prüft das und bricht sonst ab,
ohne zu schreiben. Mehrere Stücke derselben Datei werden in der angegebenen Reihenfolge nacheinander
angewandt. Die Dateien stehen im Arbeitsort mit **CRLF**: Suchstück und Ersatz mit `\r\n` anwenden,
Zeilenenden wie vorgefunden lassen; die neue Datei mit LF. „Ans Dateiende anhängen" heißt: der Block
beginnt mit **genau einer** Leerzeile und folgt direkt auf das letzte Zeilenende — keine zweite
Leerzeile (in AUF-029 stand je eine zu viel). Codierung UTF-8 (in den Stücken stehen `§`, `·` und `—`).

**Negativkontrollen nur an einer Kopie**, nie am Arbeitsstand: `src/`, `package.json`,
`vite.config.ts` und `tsconfig.json` nach `auftraege/_probe/AUF-030_nk/` kopieren und dort mutieren und
messen (`npx vitest run` mit diesem Ordner als Arbeitsverzeichnis). Die NK-Ergebnisdatei schreibt das
NK-Skript **vor** der Lieferung; danach weder die Lieferung noch die Ergebnisdatei neu schreiben.

```tsx
import { useState } from 'react';
import {
  BUNDESLAENDER,
  REGIONALE_FEIERTAGE,
  addExtraHoliday,
  holidayPreview,
  removeExtraHoliday,
  toggleRegionalHoliday,
  toggleSkippedHoliday,
  withHolidayLand,
  type PublicHolidays,
} from '../../domain/holidays';
import { formatDateWithWeekday, fromDateInput } from '../../domain/time';

/**
 * Feiertage einer Beschaeftigung: Bundesland des Arbeitsorts, regionale Tage, eine Vorschau des
 * laufenden Jahres zum Streichen und eigene Tage. Ohne Land keine Feiertage, wie bis 1.12.
 */
export function HolidaySettingsField({
  value,
  onChange,
}: {
  value: PublicHolidays | undefined;
  onChange: (next: PublicHolidays | undefined) => void;
}) {
  const [jahr] = useState(() => new Date().getFullYear());
  const [neuerTag, setNeuerTag] = useState('');
  const hinzufuegen = () => {
    const t = fromDateInput(neuerTag);
    if (value === undefined || Number.isNaN(t)) return;
    onChange(addExtraHoliday(value, t));
    setNeuerTag('');
  };
  return (
    <>
      <label className="field">
        <span>Feiertage (Bundesland des Arbeitsorts)</span>
        <select
          value={value?.land ?? ''}
          onChange={(e) => onChange(withHolidayLand(value, e.target.value))}
        >
          <option value="">keine (wie bisher)</option>
          {BUNDESLAENDER.map((l) => (
            <option key={l.code} value={l.code}>
              {l.name}
            </option>
          ))}
        </select>
      </label>
      {value !== undefined && (
        <>
          {REGIONALE_FEIERTAGE[value.land].map((r) => (
            <label key={r.key} className="field row">
              <span>{r.name}</span>
              <input
                type="checkbox"
                checked={value.regional.includes(r.key)}
                onChange={() => onChange(toggleRegionalHoliday(value, r.key))}
              />
            </label>
          ))}
          <p className="muted small">
            Feiertage {jahr}. An deinen Arbeitstagen fuellt jeder das Tagessoll auf; ein
            Urlaubstag darauf zaehlt nicht als Urlaub.
          </p>
          <ul className="vac-list">
            {holidayPreview(value, jahr).map((h) => (
              <li key={h.date}>
                <span className={h.gestrichen ? 'muted' : undefined}>
                  {formatDateWithWeekday(h.date)} {h.name}
                  {h.gestrichen ? ' (gestrichen)' : ''}
                </span>
                <button
                  className="link-btn"
                  type="button"
                  onClick={() =>
                    onChange(
                      h.eigen
                        ? removeExtraHoliday(value, h.date)
                        : toggleSkippedHoliday(value, h.date),
                    )
                  }
                >
                  {h.eigen ? 'entfernen' : h.gestrichen ? 'zurueckholen' : 'streichen'}
                </button>
              </li>
            ))}
          </ul>
          <div className="vac-add">
            <input type="date" value={neuerTag} onChange={(e) => setNeuerTag(e.target.value)} />
            <button className="btn" type="button" disabled={!neuerTag} onClick={hinzufuegen}>
              Eigenen Feiertag hinzufuegen
            </button>
          </div>
        </>
      )}
    </>
  );
}
```
