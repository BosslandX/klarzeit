# AUF-048 — Resturlaub-Übertrag ab Startwert

## Auftrag

Je Beschäftigung lässt sich ein Resturlaub-Übertrag einrichten: `Employment.vacationCarry` mit Startjahr, dem Rest, mit
dem dieses Jahr beginnt, und den verfallenen Tagen je Jahr.

- **Rechnung:** Ab dem Startjahr geht der Rest jedes Jahres ins nächste, ein Minus nicht. Der Urlaubsstand weist den
  Übertrag (`carryIn`) und die verfallenen Tage (`lapsed`) aus. Der Rest ist dann Anspruch + Übertrag − verfallen −
  genommen.
- **Eingabe:** in „Beschäftigung bearbeiten“, über die neue Komponente `VacationCarryField`.
- **Anzeige:** Auswertung und PDF-Urlaubsblock zeigen die Zeilen „Uebertrag aus <Vorjahr>“ und „verfallen“ vor
  „genommen“.
- **Ohne Einrichtung** bleibt alles wie bisher.

Elf Tests kommen hinzu, die 421 bisherigen bleiben grün.

## Warum das gebraucht wird

Plan-Punkt 8, „Urlaub“, dritter Teil. Bis hierher kannte die App keinen Übertrag.

**Festgelegt (vom Auftraggeber, nicht ändern):**

- **Rechtsgrundlage** (BUrlG, amtlicher Text, zuletzt geändert am 20.04.2013):
  - Jedes Kalenderjahr ist ein eigener, voller Anspruch (§§ 1, 3 Abs. 1).
  - Übertragen wird nur nicht genommener Urlaub (§ 7 Abs. 3).
  - Vom Mindesturlaub darf nicht zum Nachteil des Arbeitnehmers abgewichen werden (§ 13 Abs. 1).
- **Ein negativer Rest wird nicht übertragen.** Der Übertrag ist der Rest des Vorjahres, nie unter 0.
- **Verfall** trägt der Nutzer je Jahr selbst ein. Verfallen kann Urlaub nur, wenn der Arbeitgeber vorher auf den Verfall
  hingewiesen hat (BAG, Urteil vom 19.02.2019 – 9 AZR 423/16); das weiß die App nicht.
- **Jahre vor dem Startjahr** rechnet die App nicht hoch.
- **Das Startjahr ist eine Auswahl**, kein Zahlenfeld. Ein Zahlenfeld wäre während des Tippens ungültig („202“) und
  leerte sich.
- **Speicherung:** Das Feld gehört zur Feldgruppe Vertrag in `fillEmptyEmployment`. `cleanEmployment` übernimmt es nur
  gültig, sonst fehlt es ganz.

```ts
export function cleanVacationCarry(raw: unknown): VacationCarry | undefined {
  if (typeof raw !== 'object' || raw === null) return undefined;
  const x = raw as Record<string, unknown>;
  const jahrOk = (v: unknown, ab: number): v is number =>
    typeof v === 'number' && Number.isInteger(v) && v >= ab && v <= 2100;
  const fromYear = x.fromYear;
  const startDays = x.startDays;
  if (!jahrOk(fromYear, 2000)) return undefined;
  if (typeof startDays !== 'number' || !Number.isFinite(startDays) || startDays < 0) return undefined;
  const jahre = new Set<number>();
  const lapsed: { year: number; days: number }[] = [];
  for (const item of Array.isArray(x.lapsed) ? x.lapsed : []) {
    const l = (typeof item === 'object' && item !== null ? item : {}) as Record<string, unknown>;
    if (!jahrOk(l.year, fromYear)) continue;
    if (typeof l.days !== 'number' || !Number.isFinite(l.days) || l.days <= 0) continue;
    if (jahre.has(l.year)) continue; // je Jahr ein Eintrag, der erste bleibt
    jahre.add(l.year);
    lapsed.push({ year: l.year, days: l.days });
  }
  return { fromYear, startDays, lapsed: [...lapsed].sort((a, b) => a.year - b.year) };
}
```
