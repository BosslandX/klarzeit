# AUF-034 — Krankheit in Oberfläche, Auswertung und PDF

## Auftrag

Unter den Urlaubstagen in „Mehr" steht ein Abschnitt „Krankheitszeiten" für die Beschäftigung, die unter
„Urlaub fuer Beschaeftigung" gewählt ist: eintragen (von, bis, ärztliche Bescheinigung), auflisten,
entfernen, dazu ein Hinweis, wenn eine zusammenhängende Krankheit länger als sechs Wochen dauert. Ein
Urlaubstag in einem Krankheitszeitraum zeigt, ob er als Urlaub zählt. Auswertung und PDF trennen Urlaub
und Krankheit nach § 9 BUrlG und zeigen die Zeile „Krankheit (n Tage)"; das PDF erklärt sie in der
Fußnote.

## Warum das gebraucht wird

AUF-033 hat Rechnung, Speicher und Backup geliefert; ohne Oberfläche lässt sich keine Krankheit
eintragen, und Auswertung und PDF rechnen sie nicht ein.

**Festgelegt (vom Auftraggeber, nicht ändern):**

- Die Bescheinigung ist beim Eintragen **nicht** vorbelegt — die App unterstellt keine.
- Der Abschnitt nutzt die Beschäftigungsauswahl des Urlaubs; ihr Name steht nur bei mehreren
  Beschäftigungen in der Überschrift.
- Überschneidet sich ein Zeitraum mit einem eingetragenen oder liegt das Ende vor dem Beginn, meldet der
  Abschnitt das und speichert nichts. Entfernen fragt vorher nach.
- Rechtsangaben in den Texten: § 4 Abs. 1 EntgFG (Gutschrift bis zum Tagessoll), § 9 BUrlG (Urlaubstag
  mit Bescheinigung), § 3 Abs. 1 EntgFG (sechs Wochen) — am 2026-11-17 an gesetze-im-internet.de
  wörtlich geprüft, siehe AUF-033.

## Was zu tun ist

### 0 — Drei getrennte Einspiel-Läufe, in dieser Reihenfolge

**Erst wenn ein Schritt gemessen ist, wird das Skript des nächsten geschrieben.** Die Zeitstempel werden
nachgesehen, Abweichungen gehören in `nicht_erreicht`.

1. `auftraege/_probe/AUF-034_teil1.py` spielt das **Gerüst** (Schritt 1) ein → `npx tsc --noEmit` und
   `npx vitest run`, Ausgabe nach `auftraege/_ergebnisse/AUF-034_geruestlauf.txt`.
2. `auftraege/_probe/AUF-034_teil2.py` spielt die **Tests** (Schritt 2) ein → `npx tsc --noEmit` und
   `npx vitest run`, die **vollständige, wörtliche** Ausgabe von vitest (stdout und stderr, als UTF-8)
   **sofort** nach `auftraege/_ergebnisse/AUF-034_ausgangslauf.txt` — **kein Auszug**. Diese Datei danach
   **nie wieder schreiben**.
3. Erst dann `auftraege/_probe/AUF-034_teil3.py` mit der **Umsetzung** (Schritt 3).

**Jedes Suchstück kommt schon in der Ausgangsdatei seines Schritts genau einmal vor** (vom Auftraggeber
so geprüft); das Skript prüft das und bricht sonst ab, ohne zu schreiben. Mehrere Stücke derselben Datei
werden in der angegebenen Reihenfolge nacheinander angewandt.

**Zeilenenden je Datei feststellen, nicht annehmen** (in AUF-033 fand teil3 in einer LF-Datei zuerst
nichts): Die Dateien aus AUF-033 (`src/domain/sickness.ts`, `src/db/sickness.ts`,
`src/domain/sickness.test.ts`) können im Arbeitsort LF tragen, die übrigen CRLF. Je Datei: als **Bytes**
lesen; enthält sie `\r\n`, Suchstück und Ersatz **genau einmal** von `\n` nach `\r\n` umwandeln (den
LF-Text aus dem Auftrag, nie einen Text, der schon `\r` enthält), sonst unverändert anwenden. Vor dem
Schreiben prüfen, dass keine Datei `\r\r` enthält. Die neue Datei mit LF, sie endet mit einem
Zeilenumbruch. Codierung UTF-8; die Stücke enthalten `§` (U+00A7) und `·` (U+00B7), die genau so
bleiben.

Unter Windows sind `npx` und `npm` `.cmd`-Dateien: im Hilfsskript `npx.cmd`/`npm.cmd` aufrufen oder
`shell=True` setzen.

**Negativkontrollen nur an einer Kopie**, nie am Arbeitsstand: `src/`, `package.json`,
`vite.config.ts` und `tsconfig.json` nach `auftraege/_probe/AUF-034_nk/` kopieren und dort mutieren und
messen (`npx vitest run` mit diesem Ordner als Arbeitsverzeichnis). Die NK-Ergebnisdatei schreibt das
NK-Skript **vor** der Lieferung; danach weder die Lieferung noch die Ergebnisdatei neu schreiben.

```ts
/** Krankheitszeitraeume fuer die Oberflaeche, mit Neuladen nach einer Aenderung (AUF-034). */
export function useSickPeriods(): {
  periods: SickPeriod[];
  refresh: () => Promise<void>;
} {
  const [periods, setPeriods] = useState<SickPeriod[]>([]);
  const refresh = useCallback(async () => {

  }, []);
  useEffect(() => {
```

```tsx
import { useState } from 'react';
import type { Employment } from '../../domain/employment';
import {
  longSickHint,
  longSickRuns,
  sickPeriodLabel,
  type SickPeriod,
} from '../../domain/sickness';
import { fromDateInput } from '../../domain/time';
import { addSickPeriod, removeSickPeriod } from '../../db/sickness';

/**
 * Krankheitszeiten der unter "Urlaub fuer Beschaeftigung" gewaehlten Beschaeftigung (AUF-034):
 * eintragen (von, bis, Bescheinigung), auflisten, entfernen; Hinweis bei mehr als sechs Wochen.
 */
export function SickPeriodsSection({
  employment,
  periods,
  showName,
  onChange,
}: {
  employment: Employment | undefined;
  periods: readonly SickPeriod[];
  showName: boolean;
  onChange: () => Promise<void>;
}) {
  const [von, setVon] = useState('');
  const [bis, setBis] = useState('');
  const [bescheinigt, setBescheinigt] = useState(false);
  const [meldung, setMeldung] = useState('');
  if (!employment) return null;
  const eigene = periods.filter((p) => p.employmentId === employment.id);
  const lange = longSickRuns(periods, employment.id);

  const eintragen = async () => {
    const from = fromDateInput(von);
    const to = fromDateInput(bis);
    if (Number.isNaN(from) || Number.isNaN(to)) return;
    const neu = await addSickPeriod({
      employmentId: employment.id,
      from,
      to,
      certificate: bescheinigt,
    });
    if (neu === null) {
      setMeldung(
        'Nicht eingetragen: Das Ende liegt vor dem Beginn, oder der Zeitraum ueberschneidet sich ' +
          'mit einem eingetragenen.',
      );
      return;
    }
    setVon('');
    setBis('');
    setMeldung('');
    await onChange();
  };

  const entfernen = async (p: SickPeriod) => {
    if (!window.confirm(`Krankheitszeit ${sickPeriodLabel(p)} entfernen?`)) return;
    await removeSickPeriod(p.employmentId, p.from);
    await onChange();
  };

  return (
    <>
      <h3 className="sub-head">Krankheitszeiten{showName ? ` (${employment.name})` : ''}</h3>
      <p className="muted small">
        Krankheitstage entlasten das Arbeitszeitkonto an Arbeitstagen bis zum Tagessoll
        (§ 4 Abs. 1 EntgFG). Mit aerztlicher Bescheinigung zaehlt ein Urlaubstag im Zeitraum
        nicht als Urlaub (§ 9 BUrlG).
      </p>
      <div className="vac-range">
        <label className="field">
          <span>krank von</span>
          <input
            type="date"
            value={von}
            onChange={(e) => {
              setVon(e.target.value);
              setMeldung('');
            }}
          />
        </label>
        <label className="field">
          <span>bis</span>
          <input
            type="date"
            value={bis}
            onChange={(e) => {
              setBis(e.target.value);
              setMeldung('');
            }}
          />
        </label>
      </div>
      <label className="field row">
        <span>Aerztliche Bescheinigung liegt vor</span>
        <input
          type="checkbox"
          checked={bescheinigt}
          onChange={(e) => setBescheinigt(e.target.checked)}
        />
      </label>
      <button className="btn btn-block" disabled={!von || !bis} onClick={() => void eintragen()}>
        Krankheit eintragen
      </button>
      {meldung && <p className="muted small">{meldung}</p>}
      {lange.map((l) => (
        <p key={l.from} className="muted small">
          {longSickHint(l)}
        </p>
      ))}
      {eigene.length === 0 ? (
        <p className="muted small">Noch keine Krankheitszeiten erfasst.</p>
      ) : (
        <ul className="vac-list">
          {eigene.map((p) => (
            <li key={p.from}>
              <span>{sickPeriodLabel(p)}</span>
              <button className="link-btn danger" type="button" onClick={() => void entfernen(p)}>
                entfernen
              </button>
            </li>
          ))}
        </ul>
      )}
    </>
  );
}
```
