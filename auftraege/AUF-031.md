# AUF-031 — Vertrag gültig ab: frühere Vertragsstände in der Rechnung

## Auftrag

Eine Beschäftigung trägt frühere Vertragsstände (`contractHistory`), und Monats-Soll, Tagessoll und
Arbeitstage rechnen je Tag mit dem Vertrag, der an diesem Tag galt — ohne Oberfläche.

## Warum das gebraucht wird

Heute rechnet eine geänderte Wochenstundenzahl **alle Vormonate neu**: `monthSollMs` nimmt für jeden
Monat den aktuellen Wert, ebenso Tagessoll und Arbeitstage. Wer von 20 auf 30 Stunden wechselt, bekommt
rückwirkend Minusstunden. **Entscheidung des Nutzers (2026-11-17):** „Vertrag gültig ab" früh einplanen.
Dieser Auftrag liefert die Rechnung; das Formular („gilt ab" bei einer Änderung) folgt im nächsten.

Bewusst **nicht** in diesem Auftrag: der Urlaubsanspruch bei einem Wechsel der Arbeitstage im laufenden
Jahr (`annualEntitlement` rechnet weiter mit dem aktuellen Vertrag) und die mit dem Gehalt abgegoltenen
Überstunden — dafür gibt es keine geprüfte Regel im Projekt.

### 0 — Drei getrennte Einspiel-Läufe, in dieser Reihenfolge

**Erst wenn ein Schritt gemessen ist, wird das Skript des nächsten geschrieben** (in AUF-030 erstmals
eingehalten — so bitte wieder). Die Zeitstempel werden nachgesehen, Abweichungen gehören in
`nicht_erreicht`.

1. `auftraege/_probe/AUF-031_teil1.py` spielt das **Gerüst** (Schritt 1) ein → `npx tsc --noEmit` und
   `npx vitest run`, Ausgabe nach `auftraege/_ergebnisse/AUF-031_geruestlauf.txt`.
2. `auftraege/_probe/AUF-031_teil2.py` spielt die **Tests** (Schritt 2) ein → `npx tsc --noEmit` und
   `npx vitest run`, die **vollständige, wörtliche** Ausgabe von vitest (stdout und stderr, als UTF-8)
   **sofort** nach `auftraege/_ergebnisse/AUF-031_ausgangslauf.txt` — **kein Auszug**. Diese Datei danach
   **nie wieder schreiben**.
3. Erst dann `auftraege/_probe/AUF-031_teil3.py` mit der **Umsetzung** (Schritt 3).

**Jedes Suchstück kommt in seiner Datei genau einmal vor**; das Skript prüft das und bricht sonst ab,
ohne zu schreiben. Mehrere Stücke derselben Datei werden in der angegebenen Reihenfolge nacheinander
angewandt. Die Dateien stehen im Arbeitsort mit **CRLF**: Suchstück und Ersatz mit `\r\n` anwenden und
**auch beim Anhängen CRLF schreiben** (in AUF-030 kamen LF-Zeilen in CRLF-Dateien). „Ans Dateiende
anhängen" heißt: der Block beginnt mit **genau einer** Leerzeile und folgt direkt auf das letzte
Zeilenende — keine zweite Leerzeile (in AUF-029 und AUF-030 stand je eine zu viel). Codierung UTF-8.

**Negativkontrollen nur an einer Kopie**, nie am Arbeitsstand: `src/`, `package.json`,
`vite.config.ts` und `tsconfig.json` nach `auftraege/_probe/AUF-031_nk/` kopieren und dort mutieren und

export function cleanContractHistory(raw: unknown): ContractPeriod[] | undefined {
  if (!Array.isArray(raw)) return undefined;
  const jeTag = new Map<number, ContractPeriod>();
  for (const item of raw) {
    if (typeof item !== 'object' || item === null) continue;
    const x = item as Record<string, unknown>;
    if (typeof x.validUntil !== 'number' || !Number.isFinite(x.validUntil)) continue;
    if (typeof x.weeklyHours !== 'number' || !Number.isFinite(x.weeklyHours)) continue;
    if (x.weeklyHours <= 0) continue;
    const wochentage = cleanWorkWeekdays(x.workWeekdays);
    const zahl = typeof x.workdaysPerWeek === 'number' ? Math.round(x.workdaysPerWeek) : Number.NaN;
    const workdaysPerWeek = wochentage ? wochentage.length : zahl;
    if (!(workdaysPerWeek >= 1 && workdaysPerWeek <= WERKTAGE_PER_WEEK)) continue;
    const validUntil = startOfDay(x.validUntil).getTime();
    jeTag.set(validUntil, {
      validUntil,
      weeklyHours: x.weeklyHours,
      workdaysPerWeek,
      ...(wochentage ? { workWeekdays: wochentage } : {}),
    });
  }
  const liste = [...jeTag.values()].sort((a, b) => a.validUntil - b.validUntil);
  return liste.length > 0 ? liste : undefined;
}

/** Wochentage, an denen am Tag gearbeitet wird: nach dem Vertragsstand, der den Tag umfasst. */
function wochentageAm(

  date: number,

  const tag = startOfDay(date).getTime();
  return workWeekdaysOf((emp.contractHistory ?? []).find((c) => tag <= c.validUntil) ?? emp);
}
