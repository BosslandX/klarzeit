# AUF-028 — Feiertage je Bundesland berechnen

## Auftrag

Ein neues, reines Modul `src/domain/holidays.ts` berechnet die gesetzlichen Feiertage eines Jahres je
Bundesland — offline, ohne Datenbank und ohne Oberfläche.

## Warum das gebraucht wird

Feiertage erzeugen heute Minusstunden: Die App kennt sie nicht. **Entscheidung des Nutzers
(2026-11-17):** Feiertage berechnet die App je Bundesland, regionale Tage lassen sich zuschalten, eigene
Tage ergänzen oder streichen; ohne gewähltes Bundesland bleibt alles wie heute. Dieser Auftrag liefert
nur die Berechnung. Gutschrift im Konto, Auswahl im Formular und Urlaubszeitraum folgen im nächsten
Auftrag.

Die Listen sind vom Auftraggeber an den amtlichen Fassungen geprüft (2026-11-17, jede Liste als
wörtliches Zitat maschinell gegen die Seite, mit Gegenprobe): die Feiertagsgesetze der 16 Länder, für den
3. Oktober Art. 2 Abs. 2 Einigungsvertrag. Ostern nach der Rechenvorschrift der PTB („Wann ist Ostern?",
Gauß in der Form von H. Lichtenberg), dort auch „OS + 39: Christi Himmelfahrt, OS + 49: Pfingstsonntag,
OS+ 60: Fronleichnam" und die Tabelle 1980–2031. Buß- und Bettag: „Mittwoch vor dem letzten Sonntag des
Kirchenjahres" (§ 2 FTG BW), der letzte Sonntag ist der „letzter Sonntag vor dem 1. Advent" (§ 2 Abs. 2
FTG M-V), der 1. Advent der vierte Sonntag vor dem 25. Dezember. Berlin: Die geltende Gesamtausgabe („in
der Gültigkeit vom 09.05.2025 bis 17.06.2028") nennt einmalig „der 17. Juni 2028 (75. Jahrestag des
Aufstandes vom 17. Juni 1953)". **Die Daten stehen vollständig in diesem Auftrag; für ihn ist keine
Recherche nötig und keine erwünscht.**

Grenzen, bewusst: Jedes Jahr gilt die heutige Liste (ältere Rechtsstände nicht abgebildet). Sonntage
zählen nicht als Feiertage, auch wo ein Gesetz sie nennt (Hessen); Oster- und Pfingstsonntag stehen nur
in Brandenburg, weil sie dort ausdrücklich in der Liste stehen. Regional: Mariä Himmelfahrt und das
Augsburger Friedensfest (Bayern), Fronleichnam (Sachsen, Thüringen) — der Nutzer schaltet sie zu.

### 0 — Drei getrennte Einspiel-Läufe, in dieser Reihenfolge

**Erst wenn ein Schritt gemessen ist, wird das Skript des nächsten geschrieben.** Die Zeitstempel
werden wieder nachgesehen.

1. `auftraege/_probe/AUF-028_teil1.py` legt das **Gerüst** (Schritt 1) an → `npx tsc --noEmit` und
   `npx vitest run` (Gerüstlauf).

   `npx vitest run`, die **vollständige, wörtliche** Ausgabe von vitest (stdout und stderr) nach

   wieder schreiben**.

Abweichungen gehören in `nicht_erreicht`.

Die beiden neuen Dateien mit LF und UTF-8 anlegen (im Kommentar steht `§`). **Jedes Suchstück der
Umsetzung kommt in der Datei genau einmal vor**; das Skript prüft das und bricht sonst ab, ohne zu
schreiben. In Python-Skripten den TypeScript-Text so ablegen, dass die Backslashes des regulären
Ausdrucks in T1 (`\d`, `\.`) unverändert in der Datei ankommen.

**Negativkontrollen nur an einer Kopie**, nie am Arbeitsstand: `src/`, `package.json`,
`vite.config.ts` und `tsconfig.json` nach `auftraege/_probe/AUF-028_nk/` kopieren und dort mutieren und
messen (`npx vitest run` mit diesem Ordner als Arbeitsverzeichnis). Die NK-Ergebnisdatei schreibt das
NK-Skript **vor** der Lieferung; danach weder die Lieferung noch die Ergebnisdatei neu schreiben.

export function easterSunday(year: number): number {
  const k = Math.floor(year / 100);
  const m = 15 + Math.floor((3 * k + 3) / 4) - Math.floor((8 * k + 13) / 25);
  const s = 2 - Math.floor((3 * k + 3) / 4);
  const a = year % 19;
  const d = (19 * a + m) % 30;
  const r = Math.floor(d / 29) + (Math.floor(d / 28) - Math.floor(d / 29)) * Math.floor(a / 11);
  const og = 21 + d - r;
  const sz = 7 - ((year + Math.floor(year / 4) + s) % 7);
  const oe = 7 - ((og - sz) % 7);
  // Maerzdatum: der 32. Maerz ist der 1. April.
  return new Date(year, 2, og + oe).getTime();
}

export function bussUndBettag(year: number): number {
  const weihnachten = new Date(year, 11, 25);
  // Vierter Advent: der Sonntag vor dem 25. Dezember (faellt dieser auf einen Sonntag, 7 Tage).
